# Sunrock Residences: фирменный стиль

Источник: брошюра `Sunrock_dim-version_Aug_25` (InDesign, август 2025), проект Blue Reef Developments.
Используется во всех материалах для Sunrock: презентации, отчёты, лендинги, креативы.

## Шрифты

В брошюре:
- **Ambroise Std** и **Playfair Display**: заголовки, засечки, капс.
- **Adelle Sans** (Light/Regular): основной текст и вторая строка заголовка капсом.

Бесплатные замены с кириллицей, которые используем мы:
- **Playfair Display**: заголовки капсом, крупные цифры. Включать ровные цифры: `font-variant-numeric: lining-nums`.
- **Source Sans 3** (300/400/600) вместо Adelle Sans.

Приём заголовка: первая часть набрана Playfair капсом, вторая — тонким гротеском капсом, обе золотом. Пример из брошюры: «GREAT LIVING / REIMAGINED», «CONVENIENCE / AND SAFETY».

## Логотип

- Эмблема «солнце» из прямоугольных штрихов и надпись SUNROCK / RESIDENCES. Цвет золото, на зелёном — золото или белый.
- Файлы: `brand-decks/assets/logo_gold.png` (эмблема с надписью), `emblem_gold.png`, `logo_white.png`, `emblem_white.png`, `sunrock_gold_h.png` (горизонтальная надпись).
- Паттерн для обложек: крупные лучи `#284A3A` на `#2C5040`, файл `brand-decks/assets/cover_bg.jpg` (без логотипа).

## Вёрстка

- На каждой странице: «SUNROCK RESIDENCES» мелким золотым капсом слева сверху, эмблема золотом справа сверху (или слева снизу).
- Много белого поля, фото без скруглений и теней, тонкие подписи золотом.
- Обложка: разворот, слева фото, справа зелёная панель с паттерном и логотипом по центру.
- Акцентные блоки: сплошной зелёный с золотым и светлым текстом. Скругления 0, тени не используются.
- Маркеры списков: маленький золотой ромб.
