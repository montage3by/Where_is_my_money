# Мой день · Батуми — трекер

Трекер распорядка дня, недельного рациона и списка покупок. Отметки хранятся на сервере, поэтому видны с любого устройства.

- **Игра до 31 декабря** (вкладка «Игра» и шапка «Дела»): XP за дела и столько же минус за невыполненное в 00:00, уровни, серии, 5 характеристик, сезоны-ранги по месяцам, достижения. Всё считается из отметок — отдельно не хранится (`public/game.js`).
- **Сверху** — погода (Open-Meteo; город выбирается нажатием на его название, по умолчанию Казань) и курсы $→₽, €→₽, ₾→₽, $→₾ (open.er-api.com), без ключей, с кэшем на сервере.
- **Дела** — распорядок на день: раскрывающиеся дела с подпунктами, счётчик откликов на HH, подсветка текущего и просроченного. Отметки хранятся по дате, каждый день — с чистого листа. Внизу — история по дням и выгрузка всех данных в JSON (`/api/export`).
- **PSMF** (бывший «Рацион») — 3 недели белковосберегающего голодания (16.11–6.12): срок и нормы, меню Пн–Вс с графиком дня (приёмы пищи, добавки, вода), закупка на неделю с галочками, правила. Ниже — дневник «Съедено на самом деле»: пишешь свободным текстом, что съел, а если калории не указаны — их считает Claude (`ai.js`; нужен `ANTHROPIC_API_KEY`). Меню и закупка — в `plan.js`.
- **Вес** — еженедельные взвешивания с разницей к прошлому разу.
- **Правила** — правила окна питания.

Нужен Node.js 18+; единственная зависимость — `@anthropic-ai/sdk` для подсчёта калорий.

```bash
npm start            # http://localhost:3000
```

Рацион и список покупок лежат в `plan.js`. Дела добавляются и правятся прямо на сайте (кнопки «+ Добавить дело» и «Изменить»); `plan.js` задаёт только начальный распорядок для нового сервера.

## Деплой на Railway

1. **New Project → Deploy from GitHub repo** → выбрать этот репозиторий. Railway сам определит Node и запустит `npm start`.
2. **Settings → Networking → Generate Domain** — получить публичную ссылку.
3. **Добавить Volume** (правый клик по сервису → *Attach Volume*), mount path, например, `/data`.
   Без Volume отметки будут сбрасываться при каждом редеплое. Приложение само подхватывает `RAILWAY_VOLUME_MOUNT_PATH`.
4. *(Рекомендуется)* **Variables** → `APP_PASSWORD=...` — ссылка публичная, пароль закрывает её от посторонних.
   Браузер спросит логин и пароль: логин любой, пароль — этот.

### Переменные окружения

| Переменная | Назначение |
|---|---|
| `PORT` | Порт (Railway задаёт сам) |
| `APP_PASSWORD` | Если задан — включает вход по паролю |
| `ANTHROPIC_API_KEY` | Ключ Claude API — для подсчёта калорий в дневнике питания |
| `DATA_DIR` | Папка для `state.json` (по умолчанию — Volume Railway или `./data`) |

## Тренировки

Вкладка «Тренировки»: с 9 ноября — PPL-сплит дома с гантелями, вечером пн–сб по кругу Push → Pull → Legs (`plan.js` → `workout.rotation`; до этого — программа пн–пт в зале), неделя с отметками, тренировка дня
с записью подходов (кг × повторы, у планки — секунды), подсказки «прошлый раз», картинки техники
(`public/img/workout/*.jpg`). «Завершить тренировку» отмечает дело «Спортзал» в «Делах».
Прогресс — график рабочего веса по каждому упражнению и вес тела. Данные — `state.workouts`.
