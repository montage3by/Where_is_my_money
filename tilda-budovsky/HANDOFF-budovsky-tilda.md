## 2. Как теперь работаем (вариант 2 — доступ к браузеру)

Цель: Claude сам правит страницы в редакторе Тильды во вкладке пользователя.

Настройка (один раз, на компьютере пользователя):
1. Установить Claude Code (терминал или десктоп-приложение Claude).
2. Поставить в Chrome расширение **Claude in Chrome**, войти тем же аккаунтом Claude.
3. Запустить Claude Code с браузером: `claude --chrome` (или `/chrome` внутри сессии).
4. Пользователь сам входит в Тильду в этом Chrome. Пароль Claude не нужен и не просить.

Правила работы в браузере:
- Перед **Publish** и любыми необратимыми действиями (удаление блоков/страниц) —
  спросить подтверждение.
- Код в T123 менять так: открыть блок → **Content** → выделить всё (Cmd+A) → удалить →
  вставить новый код целиком → **Save** → **Publish**.
- После вставки проверить, что код начинается с `<!-- BUDOVSKY · T123` и сразу после
  комментария идёт `<style>`. Был баг: пользователь скопировал не весь файл (потерялись
  первые 100 строк с `<style>`), и CSS вывелся на страницу текстом.
- Скрипты T123 работают только на опубликованной странице / в Preview, не в редакторе.
- После публикации проверить страницу на живом сайте (десктоп + мобильная ширина).

## 3. Tilda API (только чтение) и MCP

- API Тильды **не умеет** менять страницы/блоки или публиковать. Только: список проектов
  и страниц, HTML/CSS/JS страниц, экспорт. Лимит 150 запросов/час. Тариф Business.
- Эндпоинт: `https://api.tildacdn.info/v1/<method>?publickey=...&secretkey=...`
  Методы: `getprojectslist`, `getprojectinfo`, `getpageslist&projectid=9402305`,
  `getpage&pageid=...`, `getpagefull`, `getpageexport`, `getpagefullexport`.
- MCP-сервер (сторонний, MIT, только чтение): `@theyahia/tilda-mcp`
  ```bash
  claude mcp add tilda -e TILDA_PUBLIC_KEY=... -e TILDA_SECRET_KEY=... -- npx -y @theyahia/tilda-mcp
  ```
  Инструменты: get_projects, get_project_info, get_pages, get_page, get_page_body,
  get_page_export, get_page_export_body.
- **Ключи в этот файл не записаны намеренно.** Пользователь показывал ключи скриншотом в
  прошлом чате — им рекомендовано перегенерировать ключи (Тильда → настройки сайта →
  Экспорт → API-интеграция → «Сгенерировать новые API ключи») и хранить их только в
  переменных окружения / конфиге MCP. Не вставлять ключи в код, коммиты и файлы.
- Удобно использовать API для проверки: после Publish убедиться, что на странице новая версия.

- В финальном блоке осталась строка «Запись по телефону +7 (812) 602-37-74»
  (`#bh-booking`) — можно убрать, если попросят.

CONFIG в конце кода лендинга:
```js
var CONFIG = {
  bookingUrl: '#popup:stepform',
  formSelector: '',      // '#recXXXX form' — для цели «заявка отправлена» в Метрике
```

Метрика-цели: `bh_booking_click`, `bh_phone_click`, `bh_form_success`

## 7. Стиль и правила лендингов BUDOVSKY

- Шрифт Object Sans с CDN Тильды (Regular/Heavy), фирменный цвет `#677290`,
  текст `#293244`, приглушённый `#586174`, фон-плашки `#f1f3f6`, линии `#dce0e8`.
- Весь код одним блоком T123, CSS с префиксом id-корня, без глобальных стилей.
- Картинки — только с `static.tildacdn.com` (не base64, не сторонние хостинги).
- Медицинская реклама: не обещать результат, «результат индивидуален», предупреждение о
  противопоказаниях, фото пациентов только с согласием. Не выдумывать цены, сроки акций и
  регалии врачей — только подтверждённое заказчиком.
- Не создавать собственные сообщения «заявка отправлена» — это делает форма Тильды.
